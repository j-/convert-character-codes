[convert-character-codes][0]
============================

[0]: https://skeoh.com/convert-character-codes

Convert character codes between these encoding schemes:

- Binary
- CSS
- Decimal
- Hexadecimal
- HTML
  - Decimal
  - Entity
  - Hexadecimal
- JavaScript
  - Long
  - Short
  - Unicode
- Octal
- Unicode
- URI component

```sh
# Install dependencies
bun install

# Start dev server
bun dev

# Run build
bun run build
```

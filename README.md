[convert-character-codes][0]
============================

[0]: https://skeoh.com/convert-character-codes

Convert character codes between these encoding schemes:

- Binary (e.g. `111111`)
- CSS (e.g. `\3f`)
- Decimal (e.g. `63`)
- Hexadecimal (e.g. `3f`)
- HTML
  - Decimal (e.g. `&#63;`)
  - Entity (e.g. `&quest;`)
  - Hexadecimal (e.g. `&#x003f;`)
- JavaScript
  - Long (e.g. `\u003f`)
  - Short (e.g. `\x3f`)
  - Unicode (e.g. `\u{3f}`)
- Octal (e.g. `77`)
- Unicode (e.g. `U+003F`)
- URI component (e.g. `%3F`)
